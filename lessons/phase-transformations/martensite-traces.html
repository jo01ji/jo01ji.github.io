1 · Three things that are easy to conflate
Habit plane

The broad, flat face of the lath or plate: the plane the transformation interface grows along. It is a crystallographic plane of the parent, e.g. near {557}γ for lath (≈9.4° from {111}γ), {225}γ or {259}γ for plate martensite.

Long axis

The direction the lath is longest along. It lies inside the habit plane. For lath martensite it is close to the KS parallel direction, ⟨110⟩γ ∥ ⟨111⟩α. A plate has no strong long axis inside its habit plane.

Habit plane trace

The line where the habit plane meets the polished surface: t = n × z. It depends only on the habit plane normal n and the surface. The long axis does not set it.

Rule of thumb: the elongated features on a section run along the trace, not along the long axis. Their width tells you thickness and inclination (width = T / sin θ). Their length along the trace mixes the true length, the width and the angle ψ. The long axis itself is only visible when it happens to lie along the trace (ψ = 0).

4 · Reading a lath martensite EBSD map

The hierarchy, and how it shows up on a section

Schematic section of one prior austenite grain, using the parent orientation from section 3. Each colour family is a packet (one {111}γ plane, six KS variants). Bands are blocks, split into two sub-blocks (e.g. V1/V4, 10.5° apart). Bands run along each packet's {111}γ trace. Every block has the same true thickness here, so the differences in apparent band width come only from 1/sin θ.

Prior austenite grain (PAG)

One parent orientation. Up to 24 KS variants can form in it. Typical size 10–100 µm.

Packet

Variants sharing one {111}γ ∥ {011}α plane (6 per packet, 4 packets). All laths in a packet have near-parallel habit planes, so the packet shows as one family of parallel traces.

Block

Laths of one variant pair within a packet (V1/V4, V2/V5, V3/V6 in Morito numbering). Blocks meet across high-angle boundaries (≈50–60°) that run along the trace. Typically 1–5 µm wide in section.

Sub-block and lath

Sub-blocks are the two variants of a block, 10.5° apart. Laths within one sub-block are separated by low-angle boundaries of a few degrees, and are typically 0.1–0.5 µm thick. Many lath boundaries fall below both angular and spatial resolution.

Misorientation from V1 to each KS variant (computed here from the KS relation with cubic symmetry)

If the OR were exactly KS, variant-to-variant boundaries could only take these angles. So a misorientation histogram from lath martensite shows a low-angle cluster (≈10–21°), a gap roughly from 21° to 47°, and a cluster at 47–60°. Real ORs sit between KS and NW (e.g. Greninger–Troiano) and spread these peaks by a few degrees. Boundaries in the gap usually mean prior austenite grain boundaries, or ferrite/bainite that is not martensite.

Practical reading order

  1. Index as BCC α. Low-carbon martensite is only slightly tetragonal and BCC indexing is standard. Above about 0.6 wt% C the c/a ratio can cause pseudosymmetry misindexing. Add FCC γ as a phase to catch retained austenite, which is often thin films below the step size.
  2. Pick the step size for the level you care about. About 50–100 nm resolves blocks and most sub-blocks. Individual laths usually need TKD or TEM. PAGs and packets are fine at 0.2–0.5 µm.
  3. Expect low pattern quality. Dislocation density is high, so band contrast is low and KAM is high everywhere. Compare KAM and GND only between maps with the same step size and filtering. Avoid heavy clean-up, which erases sub-blocks.
  4. Set grain thresholds by level. Around 15° picks out blocks, 2–5° picks out sub-blocks and some laths. Plot the misorientation angle histogram and compare with the table above.
  5. Reconstruct the parent austenite. Use the α–α misorientations to fit the OR and group pixels into PAGs, e.g. MTEX parentGrainReconstructor, ARPGE, or graph-cut methods. Check the OR fit residual, and watch for annealing twins in the parent (Σ3), because twin-related parents share a {111} and are easy to merge by mistake.
  6. Assign variants, packets and blocks. With the parent orientation known, each pixel gets a variant ID (V1–V24). Packet and block maps follow from the grouping above. Compare each packet's predicted {111}γ trace with the observed band direction as a sanity check.

The long axis is the hardest quantity to get from a single section. It lies in the habit plane at some angle ψ to the trace, and nothing on one surface fixes ψ. In practice it is taken from crystallography (⟨110⟩γ ∥ ⟨111⟩α for lath), or measured directly with a second face or serial sections.
